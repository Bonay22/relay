## Карточка этапа

- **Ветка:** `stage/NN-name`
- **Статус:** `planned`
- **Предыдущий этап:** `stage/NN-previous`
- **Планируемый коммит:** `type: short description`
- **Ориентир:** 3–6 продуктовых инкрементов

## Результат этапа

Какую наблюдаемую возможность Relay получит после завершения этапа.

## Учебный scope

| Уровень | Концепции | Что считается достаточным |
|---|---|---|
| Core | Необходимые для результата темы | Самостоятельно применены и объяснены в текущем коде |
| Later | Полезные связанные темы | Перенесены к первому реальному применению |
| Reference | Редкие или необязательные детали | Известно, где найти при необходимости |

Только Core может блокировать завершение этапа. При необходимости добавлять
ссылки на соответствующие ID в `GO-KNOWLEDGE-MAP.md`.
