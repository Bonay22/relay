# Relay

Relay — самостоятельный сервис надёжной доставки событий по webhook.

## Текущее состояние

Проект является Go-модулем, запускается и выводит имя и версию сервиса.

## Запуск

Из корня репозитория:

```bash
go run ./cmd/relay
```

Ожидаемый вывод:

```text
service=Relay version=0.1.0
```

## Сборка

```bash
go build ./cmd/relay
```

Команда `go build` создаёт бинарный файл, но не запускает его.
