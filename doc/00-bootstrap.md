## Новые концепции Go

### SDK и toolchain

Go SDK — установленный набор компилятора, стандартной библиотеки и команд.
Команда `go` управляет сборкой, запуском, тестами и модулями. В отличие от
Python, отдельный интерпретатор не исполняет исходный файл напрямую: Go сначала
компилирует программу в машинный код.

Основные команды этапа:

- `go version` показывает версию и целевую платформу;
- `go run <пакет>` компилирует и сразу запускает пакет;
- `go build <пакет>` только собирает пакет;
- `gofmt` приводит исходный код к стандартному формату.

### Модуль и `go.mod`

Модуль — корневая единица Go-проекта и набора его зависимостей. Его путь
записывается в `go.mod`. По роли это отчасти похоже на проект с
`pyproject.toml`, но `go.mod` не является местом для произвольных настроек
приложения: он описывает прежде всего модуль, версию Go и зависимости.

Путь модуля обычно совпадает с будущим адресом репозитория, например
`example.com/team/service`. Для локального учебного проекта допустим короткий
путь, но выбор нужно сделать осознанно до `go mod init`.

### Как читать синтаксис: ключевые слова и другие элементы

Исходный код состоит из элементов разных категорий. Их полезно различать, чтобы
не воспринимать строку программы как неделимую формулу:

- **ключевое слово** — зарезервированное слово языка с фиксированной ролью;
- **идентификатор** — имя, которое дано пакету, функции, переменной или типу;
- **литерал** — значение, записанное прямо в коде, например `"Go"`, `42` или
  `true`;
- **оператор** — знак операции, например `=`, `:=`, `+`;
- **разделитель** — символ, формирующий структуру кода, например `()`, `{}` или
  `,`.

Например, в строке:

```go
var language string = "Go"
```

- `var` — ключевое слово;
- `language` — идентификатор переменной;
- `string` — имя предобъявленного типа;
- `=` — оператор присваивания начального значения;
- `"Go"` — строковый литерал.

Ключевые слова нельзя использовать как собственные имена. Например,
`var func string` недопустимо, потому что `func` уже имеет специальное значение
в грамматике Go.

В Go 25 ключевых слов:

```text
break       default     func        interface   select
case        defer       go          map         struct
chan        else        goto        package     switch
const       fallthrough if          range       type
continue    for         import      return      var
```

Запоминать список сразу не нужно. Каждое слово разбирается перед первым
применением. Важно не путать категории: `main`, `string`, `int`, `true`, `false`
и `nil` не являются ключевыми словами. Это идентификаторы с особой заранее
определённой ролью.

### Пакет и точка входа

Каждый `.go`-файл начинается с объявления пакета. Исполняемая программа должна
содержать пакет `main` и функцию `main`. Это похоже на защищённый блок
`if __name__ == "__main__":` в Python, но в Go точка входа определяется
фиксированными именами пакета и функции.

Строка `package main` читается как «этот файл принадлежит пакету `main`».
Пакет объединяет Go-файлы одного каталога, которые собираются вместе. Имя
`main` особенное: только из пакета `main` можно собрать исполняемую программу.

Функция объявляется ключевым словом `func`:

```go
func greet() {
    // тело функции
}
```

После `func` идут имя функции, круглые скобки с параметрами и фигурные скобки с
телом. У `func main()` нет параметров. Среда выполнения Go сама вызывает эту
функцию при запуске программы. В Python похожая структура записывалась бы так:

```python
def main():
    pass

if __name__ == "__main__":
    main()
```

В Go роль этой конструкции выполняет сочетание `package main` и `func main()`.

Каталог `cmd/relay` будет содержать точку входа именно бинарного файла Relay.
Такая структура оставляет корень репозитория свободным для документации и
позже позволяет иметь несколько команд без смешивания их кода.

### Импорт, переменные и базовые типы

Импорт делает доступным другой пакет. Имена из импортированного пакета
используются с префиксом, например `fmt.Println`.

У переменной всегда есть конкретный тип. Его можно написать явно или позволить
компилятору вывести тип из значения. Короткая форма `:=` объявляет новую
локальную переменную внутри функции; это не оператор обычного присваивания уже
существующей переменной.

Объявить переменную — значит впервые создать имя, связанное со значением и
типом. Полная форма объявления выглядит так:

```go
var language string = "Go"
```

- `var` сообщает, что объявляется переменная;
- `language` — выбранное имя;
- `string` — тип;
- `=` связывает переменную с начальным значением `"Go"`.

Go умеет вывести тип из начального значения, поэтому `string` можно не писать:

```go
var language = "Go"
```

Внутри функции есть короткая форма того же объявления:

```go
language := "Go"
```

Оператор `:=` означает «объявить новую локальную переменную и вывести её тип».
Он применяется только внутри функций. Это не динамическая типизация: после
объявления `language` остаётся переменной типа `string`.

Обычный `=` не объявляет новое имя, а меняет значение уже существующей
переменной:

```go
language := "Go"      // объявление: имя появляется впервые
language = "Golang"   // присваивание: меняется существующее значение
```

В Python запись `language = "Go"` одновременно вводит имя и присваивает
значение. В Go эти действия различаются синтаксически: `var` или `:=` создают
переменную, а `=` присваивает значение уже созданной переменной.

#### Объявление без начального значения и zero value

Инициализация — присвоение начального значения в момент создания переменной.
В Go она происходит всегда. Необязателен только **явный инициализатор** —
значение, которое программист пишет в объявлении после `=` или `:=`:

```go
var language string
```

В Go не бывает переменной без какого-либо значения. Если инициализатор не
написан, язык автоматически присваивает **zero value** — нулевое значение типа.

Для базовых типов этого этапа:

```go
var text string  // "" — пустая строка
var count int    // 0
var ratio float64 // 0.0
var enabled bool // false
```

Это не `None` из Python. Значение зависит от конкретного статического типа.
Позже встретятся типы, zero value которых равен `nil`, но вводить их до этапа,
где они нужны, не будем.

Основные формы объявления и присваивания:

```go
var count int        // объявление без явной инициализации: count равен 0
var limit int = 10   // явный тип и начальное значение
var retries = 3      // тип int выведен из значения
timeout := 5         // короткое локальное объявление внутри функции
timeout = 7          // присваивание нового значения существующей переменной
```

Следовательно, `age := 27` выполняет сразу три связанных действия:

1. объявляет новый идентификатор `age`;
2. выводит для него тип `int` из литерала `27`;
3. явно инициализирует переменную значением `27`.

А `var age int` тоже объявляет и инициализирует переменную, но инициализация
неявная: язык использует zero value `0`.

После объявления тип не меняется. Например, если `timeout` получил тип `int`,
запись `timeout = "seven"` будет ошибкой компиляции.

#### `fmt.Println` и `fmt.Printf`

Обе функции находятся в стандартном пакете `fmt` и печатают в стандартный
вывод, но управляют форматом по-разному.

`Println` использует стандартное представление переданных значений, добавляет
пробелы между отдельными аргументами и автоматически завершает строку переводом
строки:

```go
name := "Alex"
age := 27
fmt.Println("name:", name, "age:", age)
```

Вывод:

```text
name: Alex age: 27
```

В имени `Println` окончание `ln` означает line: после значений добавляется новая
строка.

`Printf` принимает первым аргументом форматную строку. Буква `f` означает
formatted. Места для значений задаются форматными глаголами вроде `%s` и `%d`,
а перевод строки автоматически не добавляется:

```go
name := "Alex"
age := 27
fmt.Printf("name=%s age=%d\n", name, age)
```

Вывод:

```text
name=Alex age=27
```

Здесь `\n` — escape-последовательность внутри строкового литерала, которая явно
добавляет перевод строки. `%s` ожидает строку, `%d` — целое число. `Println`
удобен для простого вывода значений и отладки; `Printf` — когда нужно точно
контролировать текст, порядок, знаки и представление значений.

Строки имеют тип `string`. На этом этапе имя и версия сервиса могут быть
строками; отдельная модель конфигурации пока не нужна.

### Форматирование

`gofmt` — единый стандартный форматтер Go. В отличие от выбора между несколькими
Python-форматтерами, стиль отступов и пробелов здесь практически не обсуждается:
исходный файл перед проверкой форматируется стандартным инструментом.

## Небольшие примеры

Минимальная форма исполняемого пакета без поведения:

```go
package main

func main() {}
```

Фигурные скобки ограничивают тело функции. Однострочная запись выше допустима,
но обычный код читается удобнее в развёрнутом виде:

```go
func main() {
    // выполняемые команды находятся здесь
}
```

Изолированный пример zero values:

```go
package main

import "fmt"

func main() {
    var word string
    var count int
    var ready bool

    fmt.Printf("word=%q count=%d ready=%t\n", word, count, ready)
}
```

Ожидаемый вывод:

```text
word="" count=0 ready=false
```

Здесь `%q` показывает строку в кавычках, поэтому пустое значение видно как
`""`; `%d` выводит целое число, а `%t` — логическое значение.

Два способа объявить строковую переменную внутри функции:

```go
var name string = "example"
version := "0.1.0"
```

Форматированный вывод двух значений:

```go
fmt.Printf("service=%s version=%s\n", name, version)
```

Эти фрагменты показывают отдельные механизмы, но не задают целиком структуру и
содержимое программы Relay.
